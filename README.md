Solmar Nights is an open-world crime game set in the fictional coastal city of Solmar: steal cars, outrun the SCPD through a living city of traffic and pedestrians, run taxi fares and hunt hidden packages, and work a four-mission story that ends with the Big Score at the Solmar Reserve Bank. It runs entirely from static files in a desktop browser — no network, no install, keyboard and mouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
